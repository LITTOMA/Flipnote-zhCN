# 字体与 64 MiB 内存预算

本项目保持日版 v7.2.0 的原始 64 MiB 应用内存模式。启动代码在运行地址 `0x1002AC` 按 `64 MiB - 已提交内存` 申请剩余线性内存；没有切换到 80 MiB 或更大的模式。

## 字体与堆划分

思源黑体中文字库包含 7,164 个字形，BCFNT 为 2,540,684 字节。加载器另加 0x80 字节头部，共申请 2,540,812 字节；构建还强制保留至少 64 KiB 分配器余量。

主堆从 `0xDF1000` 增至 `0x10F1000`，增加 3 MiB。线性内存总量没有增加，因此工作堆的外层容量会减少同样的空间。游戏还会从工作堆中预留固定子堆；只检查主堆能否装下字体，会漏掉这些预留对画廊加载的影响。

## 画廊入口崩溃的依据

修复前的实机异常和隔离 Citra 调试均指向资源列表申请失败：`0x2658BC` 申请 10 × 0x88 = 1,360 字节，返回空指针，后续复制资源名时在 `0x26BEBC` 写入地址 0x8。此时工作堆的剩余空闲块只有 1,244 字节，另一个主堆仍有 958,040 字节空闲。相关 `TheaterBarButtonFixed` 资源与原版一致。

这说明故障来自堆间预算失衡，不能以系统还有其他内存、字体读取成功或容器哈希正确来排除。也不能据此推断所有子堆内部都已用满。

## 预算补偿

Ghidra 分析确认 `0x28BA68` 为两个打包资源缓存预留子堆并立即分配缓冲区。`0x20C158` 在空间不足时按条目状态和使用时间选择可回收条目，`0x20BF18` 删除条目，`0x2241A4` 搬移剩余数据并配套更新指针。

当前方案从这两个缓存中合计回收 3 MiB，抵消主堆扩展对工作堆其余分配的挤占：

| 项目 | 原始预留 | 汉化预留 | 差额 |
|---|---:|---:|---:|
| 主堆 | `0xDF1000`（13.941 MiB） | `0x10F1000`（16.941 MiB） | +3 MiB |
| 小资源缓存子堆 | `0x3B6000`（3.711 MiB） | `0x1B6000`（1.711 MiB） | −2 MiB |
| 大资源缓存子堆 | `0x7D0000`（7.813 MiB） | `0x6D0000`（6.813 MiB） | −1 MiB |

两个缓冲区的可用容量同步改为 `0x1B5C00`、`0x6CFC00`，各自保留原本的 0x400 字节管理余量。不能只改子堆预留而保留更大的缓冲区申请。

本次没有修改动画帧数、画布、音轨或编辑器容量限制，也没有裁减字体。缓存可驻留的数据量减少，可能增加淘汰和重新加载；完整在线浏览、并发请求及长时间编辑仍需另外验证。

## 可复核的补丁位置

以下偏移均相对于解压后的 `.code`，运行地址另加 `0x100000`：

| 文件偏移 | 用途 | 当前值 |
|---|---|---|
| `0x2AC` | 原 64 MiB 总额度指令 | `0xE2600301`，保持原值 |
| `0x2CC` | 主堆大小 | `0x10F1000` |
| `0x18BB50` | 小缓存子堆大小 | `0x1B6000` |
| `0x18BB58` | 小缓存可用容量 | `0x1B5C00` |
| `0x18BAC0` | 大缓存子堆大小指令 | `0xE3A0086D`，即 `mov r0, #0x6D0000` |
| `0x18BB5C` | 大缓存可用容量 | `0x6CFC00` |

`font-loader-code.json` 固定原字节和结果哈希。字体加载器的 C/汇编没有改动，这四处缓存调整直接修改原游戏初始化常量。`FontMemoryBudget` 在 plan/build 中同时核对总额度、主堆、缓存预留、缓冲区容量与字体大小。

修复后的 `.code` SHA-256 为 `2340ADCBB81249CD40C0E5278D296422105CCB1F3D9126A12F43AC977EB20E40`；CIA SHA-256 为 `DCA2AECA6940780966D7E81C320B53C24138FE71555769134A067FD6FA9B7C4B`。

## 验证范围

- Windows 构建完整回读 2,093 个资源，80 项覆盖通过；回归验证包含确定性重建、原版只读及字体像素约束。
- 新增回归拒绝三类错误：字体扩堆后漏掉缓存补偿、缓冲区容量超过缩减后的子堆、意外改成 80 MiB 分配额度。
- 2026-10-26，提供修复后的隔离 Citra 程序后，用户确认原先出错的入口“现在确实可以了”。该反馈确认本次入口故障改善，未指明另行进行过实机复测。
- 不将入口验证等同于私服接入成功、最大容量作品或所有联网页面的验证。
