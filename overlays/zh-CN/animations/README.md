# 示例动画文字覆盖层

`coverage.json` 描述 12 个示例、506 帧的覆盖范围；9 个 `*-bitmap.json` 提供实际修改配方，07、10、11 保持完整文件字节不变。`translation-layout.json` 保存译文、原文、文字笔画区域、对齐锚点与字号。

配方只能改完整解码后的三层索引位图：`erase` 擦除原文字，`ink1/ink2` 绘制汉字。每个矩形固定原像素 SHA-256；编译器检查掩码之外全部像素、颜色、图层深度、帧参数和音轨。掩码为低位优先的一位位图，经 zlib 压缩后存为 Base64。

中文使用 `fonts/fusion-pixel-12px/` 的缝合像素体原生 12px 或 2 倍 24px，不抗锯齿、不拉伸字形，沿用原左/右/居中对齐。通过 `author-masks.py --input <原版CIA>` 重制配方，正常构建不需要 Python 或渲染字体。

完成文字修改后，外部 libkwz 用 `UpdateThumbnail` 从原选定完整帧生成 80×64、质量 90 的 JPEG，并重新签名。缩略图是标准整图编码；动画正文仍遵守掩码外像素完全不变的约束。

构建前会扫描所有完整解码帧中已审阅文字块的实际出现，检查布局范围和擦除掩码是否覆盖首尾帧。完整复核范围及边界漏帧回归检查见 [逐帧复核](../../../docs/ANIMATION_REVIEW.md)。
